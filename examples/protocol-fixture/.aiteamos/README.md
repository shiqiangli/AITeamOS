# AITEAMOS Public Demo Workspace

This `.aiteamos` workspace is a committed, synthetic Team Member OS example. It is
separate from the repository root `.aiteamos` self-hosting workspace so public demos
can be validated and browsed without exposing private workspace records.

Storyline:

- `protocol-runtime-bot` completes a managed digital run for `conversion-runtime`.
- `protocol-release-hybrid` completes an assisted ingest run from a handoff.
- `protocol-reviewer-human` reviews the work and keeps approval authority human.
- `protocol-ci-service` records a memory-health automation run.
- `MEM-protocol-runtime-contract` is approved, versioned, bound, granted, and
  injected into the runtime run context.
